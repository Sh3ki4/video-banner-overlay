# Video Banner Overlay 2.1 для Windows

Программа накладывает `banner.mp4` поверх исходного ролика. Основное видео продолжает идти на фоне, баннер показывается **целиком**, без растягивания и обрезки. Длительность исходника не меняется.

> Важно: запускайте именно `RUN.bat` из папки **VideoBannerOverlay**. Старая программа `VideoBannerInserter` вставляла баннер отдельным полноэкранным сегментом и для этого режима не подходит.

## Что уже лежит в комплекте

- `ffmpeg\bin\ffmpeg.exe` и `ffprobe.exe` — отдельно устанавливать FFmpeg не нужно;
- Python-скрипт обработки;
- запускатор `RUN.bat`;
- папки `INPUT` и `OUTPUT`.

Нужен только Python 3.8 или новее: https://www.python.org/downloads/windows/

## Как пользоваться

1. Положите исходные `.mp4` в `INPUT`.
2. Положите рекламный ролик под именем `banner.mp4` рядом с `RUN.bat`.
3. Дважды щёлкните `RUN.bat`.
4. Готовые файлы появятся в `OUTPUT`.

При правильном запуске первая строка окна будет:

```text
=== VIDEO BANNER OVERLAY 2.1 ===
Режим: видео идёт на фоне, баннер показывается ЦЕЛИКОМ без обрезки.
```

## Настройки по умолчанию

- баннер появляется с отметки 50% длительности;
- его размер ограничен 94% ширины и 24% высоты кадра;
- нижняя граница находится на 72% высоты — над нижними субтитрами;
- пропорции всегда сохраняются, весь кадр баннера вписывается внутрь зоны;
- фоновый звук во время рекламы снижается до 35%;
- звук баннера воспроизводится поверх исходника.

## Настройка положения и размера

```bat
RUN.bat --position-percent 50 --banner-width-percent 94 --banner-height-percent 24 --banner-bottom-percent 72 --background-volume-percent 35
```

- `--position-percent` — момент появления, 5–95%;
- `--banner-width-percent` — максимальная ширина, 10–100%;
- `--banner-height-percent` — максимальная высота, 5–60%;
- `--banner-bottom-percent` — нижняя граница по высоте кадра, 20–100%;
- `--background-volume-percent` — громкость исходника во время рекламы, 0–100%.

Чтобы поднять баннер, уменьшите `--banner-bottom-percent`. Чтобы увеличить его, поднимите `--banner-height-percent`, но исходные пропорции и полный кадр всё равно сохранятся.

FFmpeg распространяется на условиях лицензии, приложенной в `ffmpeg\LICENSE`.

Программа работает только с локальными файлами, ничего не загружает в интернет и не обходит DRM.
